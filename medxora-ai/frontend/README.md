# MedXora AI — Frontend

React 18 + Vite dashboard for the MedXora AI autonomous trading strategy engine.

## Start

```bash
npm install
npm run dev
```

Dashboard: http://localhost:5173 — requires the backend running at http://127.0.0.1:8000.

## Pages

| Page | Description |
|------|-------------|
| Command Center | KPIs, pipeline status, batch analytics |
| Strategies | Full strategy library with filters |
| Backtests | All backtest history |
| AI Agents | 20-agent registry + orchestration workflow |
| Evolution Lab | Genetic mutation controls + generation tracking |
| Portfolio | Diversified strategy selection |
| Risk Center | Portfolio risk analytics |
| Logs | System log viewer with level filter |
| Settings | MT5 config + phase roadmap |

## Tech

- React 18
- Vite
- Recharts (charts)
- Axios (API calls)
- WebSocket (live pipeline streaming)
